# id 决定数据文件夹、开机自启项和剪贴板加密，发给别人以后不要再改。
key      = example

nick     = 小柴

# 默认造型（art/example/variants.txt 里的第一个）
look     = short

# 另一只宠物的 id（两只都开着会互相打招呼、串门）；不填就是一只
