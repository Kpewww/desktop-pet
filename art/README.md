# 怎么改像素图

所有美术都是纯文本，每只一个文件夹：`art/aly/`、`art/kpew/`。改完运行 `.\build.ps1 art -Char aly`（或 `kpew`）生成图集，再 `.\build.ps1 run -Char aly` 看效果。
预览图在 `art/out/<宠物>/preview/`：
- `clip_*.png`：每个动作的每一帧，浅色和深色背景各一行
- `gif_*.gif`：按真实时长播放的动图
- `_sheet.png`：所有动作的总览（有多个造型时，其余造型是 `_sheet_<造型>.png`）

## 文件（在 `art/<宠物>/` 里）
| 文件 | 内容 |
|---|---|
| `palette.txt` | 调色板：一个字符对应一种颜色。`>X` 表示挨着这种颜色的外轮廓用 `X` 这种颜色 |
| `parts/*.txt` | 部件：头、表情、耳朵、身体、手臂、腿、尾巴、特效…… |
| `clips.txt` | 动作：每一帧由哪些部件组成、放在哪、停多久 |
| `variants.txt` | 可选：几个造型（发型、大衣……），每行"造型名 项目…"，项目是这个造型不画的图层，或者 `原部件=新部件`（换成别的部件画，比如示例宠物的短发）。没有这个文件就只有一个造型 `base` |

`art/fonts/` 放像素字体的授权文件（BDF 源文件太大，不进 git，见下文），`art/tool/` 是构建工具，两只共用。
吃的东西对应哪个动作、第几帧说什么，写在 `assets/<宠物>/character.txt` 里。

## 部件格式
```
part 名字 [origin=x,y] [锚点名=x,y ...] [mirror=部件] [sym=N] [from=部件 [flip]]
..网格..
end
```
- 每个字符是调色板里的一种颜色，`.` 是透明。外轮廓由工具自动描，部件里不用画。
- `origin`：部件的定位点。默认是最下面一行的中间。
- 锚点（比如 `neck=10,0`）：给别的部件挂靠用。
- `sym=N`：只写左半边（第 0 列到第 N 列），右半边自动镜像。
- `from=底图 [flip]`：在已有部件上改。网格里 `_` 表示保留底图，`.` 表示擦掉，其他字符表示涂上这种颜色。加 `flip` 就先把底图左右翻转。
- `mirror=部件`：镜像动作（比如 walk_l）里改用这个部件，而不是把原部件翻过来。比如一侧的挑染，就是靠它在镜像时还保持在同一侧。

## 动作格式
```
pose 名字 图层=部件@位置 ...          # 定义一组可以复用的图层
clip 名字 [loop] [mirror=别的动作]
  f 毫秒 [+pose名] [~] 图层=部件@位置 图层=@位置 图层=- ...
```
- 位置有两种写法：`dx,dy` 表示相对画布原点（脚底中心）的偏移；`图层.锚点[:dx,dy]` 表示挂在另一个图层的锚点上。
- `~` 表示沿用上一帧的所有图层，这样只需要写有变化的部分。
- `图层=-` 表示去掉这个图层。
- `layers` 那一行规定了图层的绘制顺序；`|` 右边的图层画在自动描边之后。

## 造型和图集
每个造型生成两份图集：`assets/<宠物>/<造型>.atlas`（完整）和 `<造型>_plain.atlas`。后者是同样的动作，但不画 `ears` 和 `tail` 两个图层，给设置里的耳朵尾巴开关用。所以不要让别的图层挂在 `ears` 或 `tail` 图层的锚点上。

`variants.txt` 里的造型也是这样实现的：动作表里把所有可选图层都写上（比如长发、短发、大衣），每个造型去掉用不到的那几层。各造型的动作和帧完全一样，程序能在动画中途换图集（换发型的小剧场就是这么做的）。

## 规则（详见 docs/ANIMATION_GUIDE.md）
- 眼睛由程序画：帧里放 `eyes=v1.eyes.gaze@head.eyes`，这样才能看鼠标、随机眨眼。表情需要特殊眼睛时，直接放对应的眼睛部件。
- 举牌的牌子也由程序画（上面的字会变）：牌子挂在 prop 图层部件的 `sign` 锚点上（导出为 `prop.sign`），锚点是棍子顶端最左边那个像素，牌子的下沿就贴在这里。只有带这个锚点的帧才显示牌子；`sign_up` 前两帧牌子会展开，`sign_down` 前两帧会收起。
- 走路和跑步的速度必须和步幅对应：着地的脚每帧往后移 2px；走路每帧 110ms，对应 `Config.WalkSpeed`，跑步每帧 70ms，对应 `Config.RunSpeed`。
- 新加的动作要带进入和退出的过渡帧，不要硬切。

## 字体
气泡里的字用的是 Fusion Pixel Font 12px（SIL OFL 1.1）。BDF 源文件大约 5MB，放在 `art/fonts/` 里但不进 git。需要重新生成 `assets/pixel12.font` 时，从 [Fusion Pixel Font 的发布页](https://github.com/TakWolf/fusion-pixel-font/releases) 下载 `fusion-pixel-font-12px-proportional-bdf`，把里面的 `fusion-pixel-12px-proportional-zh_hans.bdf` 放进 `art/fonts/`，再运行 `.\build.ps1 art`。

## 换成手绘
想用 Aseprite 手绘时，给 `art/tool/` 加一个读取 Aseprite 导出文件（JSON 数组格式 + PNG）的导入器即可。App 读取的图集格式不用改。
