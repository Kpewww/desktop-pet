# 桌宠动画规范

画新动作、调整动作时都照这份规范来，目标是**流畅**和**像她**。

## 画布与像素
- 每帧画布 80×80。Q 版约 2.5 头身，身高约 56px，头顶留出空间给跳跃和特效。
- 所有颜色都必须来自 `art/palette.txt`，构建工具会检查。
- 外轮廓由构建工具自动描，颜色是深紫褐色，不用纯黑。内部线条手画。
- 紫色挑染永远在她自己的左侧：正面图在画面右边。不能靠直接镜像出来。
- 头发是近黑色，一定要带冷灰紫高光，否则在深色壁纸上会糊成一团。

## 节奏
- 每一帧单独设停留时长：关键姿势停得久，过渡帧一闪而过。不要所有帧等长。
- idle 呼吸：吸气、呼气两个端点各停约 300ms，中间的过渡帧约 120ms。
- 眨眼由程序随机触发，间隔 2–6 秒，偶尔连眨两下，不画进 idle 循环里。

## 过渡
- 每个状态都有进入和退出的过渡动作（坐下、起身、躺下、起床、转身、停步），不同姿势之间不能硬切。
- 只有被抓起这类突发事件会直接切换，而且也要有专门的反应帧（grabbed）。
- 同一组动作（比如 idle 的正面和左右转头）帧数和节奏必须完全一致，程序切换时会保持当前帧位置。

## 移动
- 走路速度由步幅决定：每个走路循环前进的距离，等于两步的步幅。改了走路帧，也要一起改速度（`Config.cs`），否则脚会打滑。
- 起步和停步有约 150ms 的加速和减速；停步时头发往前多甩一下再回来（walk_stop）。
- 落地先压扁（身体变矮变宽 1–2px），再回弹。反弹逐次减弱。

## 视线
- 眼睛由程序画，一共 5×3 个视线档位；视线切换时一次只移一档，每档约 100ms。
- 鼠标在很远的一侧时，换成 3/4 朝向的头（idle_l34 / idle_r34）。
- 表情自带的特殊眼睛（笑眯眼、生气眼、蚊香眼、闭眼）直接画在帧里，这时不画程序眼睛。
