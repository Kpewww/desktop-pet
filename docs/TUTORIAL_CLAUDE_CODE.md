# 用 Claude Code 做一只自己的桌宠（详细教程）

这个仓库是一个**预制包**：
- 引擎、几十个动作、换装、番茄钟、剪贴板举牌、防干扰这些功能都已经做好了。
- 你要做的，是让 Claude Code 照着你的描述和照片，把示例宠物「小柴」改造成你的宠物。
- 不用会写代码，主要是**描述清楚**和**看预览图给反馈**。

整个过程大概：
- 准备 15 分钟。
- 第一版形象 1～2 小时（主要是 Claude 在干活，你看图提意见）。
- 之后想加什么随时加。

---

## 0. 你需要准备什么
| 东西 | 说明 |
|---|---|
| Windows 10 或 11 的电脑 | 宠物只能在 Windows 上跑 |
| Claude 订阅 | Claude Code 需要 Claude Pro / Max（或团队版），也可以用 API 计费。画像素图比较费额度，推荐 Max |
| Claude Code | 下面第 1 步安装 |
| Git | 用来下载这个仓库：<https://git-scm.com/download/win>，一路默认安装 |
| 参考照片 | 想画谁就准备谁的照片：正脸 1～2 张、全身 1～2 张、平时爱穿的衣服各一张。5～15 张就够 |
| 想好的设定 | 名字、性格、口头禅、爱吃什么、想要哪些功能（后面有清单） |

## 1. 安装 Claude Code
三种方式任选一种：
- **桌面版**（最简单）：安装 Claude 桌面 App，登录后在左侧选「Code」。
- **VS Code 扩展**：安装 [VS Code](https://code.visualstudio.com/)，在扩展市场搜索「Claude Code」安装，登录。
  - 这种方式能同时看到文件和预览图，推荐。
- **命令行**：按官方文档安装 Claude Code CLI，在终端里输入 `claude` 启动。

安装方法会更新，以官方文档为准：<https://docs.claude.com/claude-code>。

## 2. 下载这个仓库
打开 PowerShell（开始菜单搜 PowerShell），输入：

```powershell
cd $HOME\Documents
git clone https://github.com/Kpewww/desktop-pet.git
cd desktop-pet
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned   # 允许运行本地脚本（只需要一次，问你时输入 Y）
.\build.ps1 art
.\build.ps1 run
```

任务栏上方出现一只小柴，说明环境没问题。右键它可以看菜单，右键 → 退出。

> 不想自己敲命令也行：直接进第 3 步，让 Claude Code 帮你执行。

## 3. 在 Claude Code 里打开这个文件夹
- **桌面版**：选择项目文件夹 `Documents\desktop-pet`。
- **VS Code**：文件 → 打开文件夹 → `desktop-pet`，然后点右上角的 Claude 图标。
- **命令行**：在 `desktop-pet` 文件夹里运行 `claude`。

第一句话先让它熟悉项目（可以直接复制）：

```
先读一下 README.md、docs/MAKE_YOUR_PET.md 和 art/README.md，了解这个桌宠项目的结构，
特别是一只宠物由哪些文件组成、怎么构建和预览。读完简单告诉我你的理解，先不要改任何东西。
```

## 4. 选模型和思考强度
Claude Code 可以切换**模型**和**思考强度（effort）**。用 `/model` 命令（或界面上的模型选择）切换。

| 阶段 | 模型 | 强度 | 为什么 |
|---|---|---|---|
| 做计划、设计形象 | 最强的模型（Opus） | 高（high），复杂时用最高（max） | 要同时考虑几十个部件和动作，规划错了后面返工更贵 |
| 画像素部件、改动作表 | Opus | 高 | 像素图是一格一格的文本，对精确度要求很高；画错一格就会穿帮 |
| 看预览图、按反馈小修 | Opus | 中（medium） | 改动范围小，不需要想太久 |
| 改台词、改颜色、改名字、调数值 | Sonnet，或者 Opus 低强度 | 低（low） | 简单的文本修改，省额度 |
| 编译、打包、跑测试 | 任意 | 低 | 只是执行命令 |

小技巧：
- 一开始就用最强模型 + 高强度把计划和第一版形象做好，比便宜模型来回改十轮省事得多。
- 额度快用完时，把"改台词、换颜色"这种小事留给 Sonnet。

## 5. 先进 Plan 模式（计划模式），把需求说清楚
**为什么要先做计划**：
- Plan 模式下 Claude 只读不改。它会先调研、问你问题、写出完整计划，等你批准才动手。
- 做宠物要改几十个文件，先对齐方案能避免做到一半发现方向不对。

**怎么进入**：
- 在输入框里按 **Shift+Tab** 切换模式，直到显示 "plan mode"。
- 或者在界面的模式选择里选「Plan」。

**怎么描述你的宠物**：越具体越好。下面是一个可以直接改着用的模板：

```
我想基于这个项目做一只自己的桌宠，用 .\build.ps1 new 新建，key 叫 mochi。

【是谁】我的猫"麻薯"拟人化：一个扎丸子头的小女孩，橘白色猫耳朵和尾巴。
【样子】
- 头发：深棕色丸子头，刘海齐眉
- 眼睛：圆圆的大眼睛，琥珀色
- 衣服（默认）：奶黄色毛衣 + 格子短裙 + 白袜子
- 衣柜里再加：粉色睡衣、黑色卫衣+牛仔裤、白色连衣裙
- 换发型：默认丸子头，剪头发变短发，生发药水变长卷发
【性格和说话】傲娇，自称"本喵"，口头禅"哼～""喵！"
- 被戳：  喵？／别碰本喵！
- 被摸头：呼噜呼噜～
- 生气到爆发：本喵要挠你了！
【爱吃的】小鱼干、猫条、冰淇淋（吃冰淇淋会冻到脑袋）
【功能】保留全部功能（举牌、番茄钟、提醒、陪看、防干扰），快捷键 Ctrl+Alt+M。
【照片】我会上传几张照片，形象请参考照片。

请先看看示例宠物用了哪些部件和动作，然后给我一个分阶段的计划：
先出调色板和头部、耳朵、发型的预览给我看，确认后再做全身和其他动作。
有不确定的地方先问我。
```

**Claude 出计划后**：
- 认真看一遍，不满意就直接说"第 3 步改成……"。
- 满意了点「批准 / Approve」（或者回复"可以，开始做"），它才会开始改文件。

## 6. 上传照片
**两种方式**：
- **直接拖进对话框**（或粘贴截图）。适合几张照片，Claude 马上能看到。
- **放进 `reference_pics/` 文件夹**，然后告诉它：
  ```
  参考照片在 reference_pics/ 文件夹里，请一张张看，然后总结出：发型和发色、脸型、
  眼睛、标志性特征、每张照片里的衣服。先不要画，总结给我确认。
  ```
  这个文件夹已经写进 `.gitignore`，**不会被提交或上传到 GitHub**。

**隐私提醒**：
- 照片只在你本机的对话里用。
- 不要把照片放到仓库的其他文件夹，也不要提交。
- 也可以要求 Claude："照片是私人的，不要复制到别的地方，用完把缩略图删掉。"

**让它先"看懂"再画**：
- 先确认它总结的特征（比如"左边有一缕挑染""总戴细框眼镜"）。
- 再让它定调色板。
- 这一步做对了，后面画出来才像。

## 7. 看预览、给反馈（最重要的一步）
Claude 每改完一轮会运行 `.\build.ps1 art -Char mochi`，生成预览图：
- `art\out\mochi\preview\_sheet.png`：所有动作一览
- `art\out\mochi\preview\clip_idle.png` 等：每个动作的每一帧
- `art\out\mochi\preview\_outfits.png`：所有衣服

你可以：
- 在文件管理器里双击打开这些图。
- 或者让 Claude 做一张"原来 vs 现在"的对比图给你看。

**给反馈要具体**，像这样：
- "脸太圆了，下巴收窄一点，整体瘦一点。"
- "耳朵不明显，跟头发一个颜色看不出来，换成浅色、再大一点。"
- "走路的时候尾巴被头发挡住了。"
- "眼睛离得太近。"
- "第二套衣服的裙子颜色再浅一点。"
- "这个开心的动作看起来像兔子，我想要小狗的感觉。"

一般 2～4 轮就能满意。
- 每轮改完记得看图，不满意就继续说。
- 满意了说"形象定了"。

## 8. 加功能、改台词、加吃的
形象定了以后，可以一项一项加（这些可以切到中/低强度）：
- **吃的**："加一个吃小鱼干的动作：叼着小鱼干，嚼两下，开心地摇尾巴，台词'小鱼干！'"
- **衣服**："衣柜再加一套圣诞装：红色斗篷 + 白色毛边。"
- **台词**：
  - "把被戳的台词改成：……"
  - 或者运行起来以后，自己在「右键 → 打开小窝 → 台词」里加，马上生效。
- **两只做伙伴**："我想再做一只（我自己），和麻薯互相认识、会串门。"
  - Claude 会帮你设置 `partner` 和 `duty`。
- **调手感**："散步再少一点""说话再少一点"。
  - 设置里大部分能直接调，改不了的再让 Claude 改。

每做完一项，让它跑一下测试（`.\build.ps1 test`），再运行看看。

## 9. 运行、打包、送人
```powershell
.\build.ps1 run -Char mochi     # 自己先试
.\build.ps1 dist -Char mochi    # 打包：dist\<编号>-<版本>.zip
```

把 zip 发给朋友：
- 解压到一个固定的文件夹，双击 exe 就能用，不用安装。
- 第一次打开如果 Windows 提示"已保护你的电脑"，点"更多信息" → "仍要运行"。

## 10. 常见问题
| 问题 | 怎么办 |
|---|---|
| `.\build.ps1` 报"禁止运行脚本" | 运行一次 `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned` |
| 杀毒软件报毒 | 自己编译的程序没有数字签名，加到信任列表即可 |
| `art` 构建报错 "xxx.txt(行号)" | 把报错原文发给 Claude，它会修 |
| 预览图里某个动作穿帮（手脱节、飘起来） | 告诉 Claude 是哪个动作第几帧（`clip_xxx.png` 里每帧下面有编号） |
| 额度不够用 | 计划和画图用强模型，小改用 Sonnet；一次说清楚多个修改，少来回 |
| 想从头再来 | 删掉 `art\<key>\` 和 `assets\<key>\`，重新 `.\build.ps1 new <key>` |
| 改坏了想回退 | 让 Claude 用 git 回到上一个能用的版本（建议每做完一阶段让它 commit 一次） |
